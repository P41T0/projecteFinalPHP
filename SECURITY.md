# Security

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues, discussions, or pull requests.

If GitHub private vulnerability reporting is enabled for this repository, open the repository's **Security** tab and use **Report a vulnerability**. If that option is unavailable, contact a repository maintainer through a private channel before sharing technical details. Do not include credentials or real user data in a report.

Include the affected component, reproduction steps using test data, potential impact, and any suggested mitigation. Maintainers can then investigate and coordinate a fix privately.
